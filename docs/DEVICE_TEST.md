# Физическая проверка / Physical qualification

Статус: НЕ ПРОВЕРЕНО. Пользователь сообщил, что физического устройства сейчас нет.

Для каждого Pixel10Pro/11Pro и каждой stable/beta сборки отдельно запишите: модель, точный Build ID, Google Play system update, модель AirPods и прошивку. Не публикуйте MAC, полные серийные номера или сырой дамп.

1. Системное спаривание двойным тапом по передней части кейса. Запустить AirMode, Bluetooth разрешить; уведомления сначала отклонить.
2. Открытый кейс и оба наушника в ушах: сравнить все три процента с независимым показанием; неизвестное —.
3. Каждый из четырёх режимов из приложения: записать подтверждённый mode и фактическое слышимое изменение. Отсутствие ACK должно закончить loading≤1.5s и показать ошибку.
4. Добавить плитку, проверить выбранный цикл, синхронизацию с приложением. Переключить ножкой; UI/плитка обновляются≤2s без обратной команды.
5. Подключить заново: ровно один тихий popup≤8s после первого достоверного заряда. При отключении убрать живое уведомление, остановить сервис≤30s.
6. Bluetooth выкл/вкл, звонок при смене режима, закрытый удалённый кейс>2min, один наушник в кейсе.
7. Сопряжённые две пары, переименованная пара: проверить выбор и отсутствие смешивания BLE данных.
8. AirPods4 безANC и сторонние наушники: никакие пакеты listening mode не уходят; кнопки/плитка недоступны.
9. Убить процесс, нажать плитку; перезагрузка с подключённой парой при autostarton и off.
10. Нет INTERNET/location/microphone permissions; мобильный трафик пакета0. Заряд и плитка работают при отказе POST_NOTIFICATIONS.
11. Pixel8 cold start до main<1s: измерить на реальном устройстве, не по времени эмулятора.

Pass требует фактические результаты, не галочки из документации. Собранный APK не заменяет этот чеклист.
